# Giant Mario Mod

A browser game library with a live mod editor for Giant Mario (Super Mario Bros. + the Giant Mario v1.2 hack).

- Add your own ROM files once; they stay saved in your browser on that device.
- NES games run on jsnes, with touch buttons, keyboard, mouse and gamepad controls and Game Genie / RAM cheats.
- SNES, Game Boy, GBA, Genesis, Master System, Game Gear, N64 and DS games run on EmulatorJS.
- Giant Mario settings change the game live: timer, lives, jump height, run and walk speed, music, rainbow star, brick breaking and smashing through blocks.

No games are included. Load your own legally obtained ROMs.

Uses the Giant Mario v1.2 and Invincible Mario patches (romhacking.net hack #6142), jsnes (Apache 2.0, see LICENSE-jsnes.txt) and EmulatorJS.
